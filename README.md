Aim
To write a Python program using Pandas to create a DataFrame and perform 

operations like head, tail, info, describe and sorting.

Algorithm

1.Start the program.

2.Import the Pandas library.

3.Create a dictionary containing Name, Marks, Age, Course and State.

4.Convert the dictionary into a DataFrame using pd.DataFrame().

5.Display the DataFrame using print().

6.Use head() to display the first rows.

7.Use tail() to display the last rows.

8.Use info() to display information about the DataFrame.

9.Use describe() to display statistical details.

10.Use sort_values() to sort marks in ascending order.

11.Stop the program.
